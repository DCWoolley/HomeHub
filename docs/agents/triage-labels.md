# Triage labels

The user confirmed the default vocabulary on 15 October 2026.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | Requires maintainer evaluation |
| Needs information | needs-info | Waiting for more information |
| Ready for agent | ready-for-agent | Fully specified and ready for agent implementation |
| Ready for human | ready-for-human | Requires human implementation |
| Will not action | wontfix | Will not be implemented |

Apply the label for the current state, rather than all labels together. Specifications produced by to-spec receive ready-for-agent.
